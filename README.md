# Job Finder

A phone-first app for browsing, filtering and tracking job search results.

This repository holds **only the app code** and is served with GitHub Pages. It contains no
job data or personal details. The app reads the job list, saved jobs and search criteria from
a private repository through the GitHub API, using a fine-grained access key that is entered
once on the phone (Criteria → Connect to GitHub) and kept only in that browser.

Without a key, the app shows made-up sample jobs.
