    Connect to GitHub

    The job list, saved jobs and criteria are kept in your private GitHub repo. Paste an access key once and this phone remembers it. Nobody without the key can see the list.

    How to get an access key
    1. On GitHub open Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories → your job-searcher repo.
    3. Permissions → Repository → Contents: Read and write. Nothing else.
    4. Generate, copy it, and paste it above.
